# Release checklist — IDEA-001 (example)

- [x] Proposed version and scope documented.
- [x] Requirements, architecture, and acceptance-criteria references included.
- [x] Factory and sample tests executed successfully in this workspace.
- [x] Python compilation check executed successfully.
- [x] Limitations and unrun security scans disclosed in the sample review.
- [ ] Required GitHub CI and dependency-review checks pass on the release PR.
- [ ] Human approves merge and publication.
- [ ] Tag and publish release notes only after approval.

This checklist is an example and does not assert that a GitHub PR, CI run, tag, or release exists.
