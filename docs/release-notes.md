# Sample release notes — IDEA-001

## Proposed version: 0.1.0

Initial offline word-count CLI. It counts Unicode word sequences from a UTF-8 file, handles empty input, and reports file/decoding errors. The implementation uses the Python standard library and includes a small test suite.

Traceability: IDEA-001; TASK-001 / AC-001, AC-002, AC-003; TASK-002 / AC-004.

Limitations: tokenization is not language-specific; only plain UTF-8 text files are supported. This is a release-preparation example, not a published release.
